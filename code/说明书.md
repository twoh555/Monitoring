# 转基因作物花粉漂移监测与风险评估系统软件说明书

## 1. 软件基本信息

| 项目 | 内容 |
| :--- | :--- |
| **软件全称** | 转基因作物花粉漂移监测与风险评估系统 |
| **软件简称** | 花粉漂移监测系统 |
| **版本号** | V1.0 |
| **开发语言** | Python 3.x |
| **运行平台** | Windows / Linux / macOS |
| **硬件要求** | 配备串口通信接口的计算机，STM32或其他环境传感器硬件（可选） |

## 2. 软件简介

本软件是一款集**环境实时监测**、**花粉扩散模拟**与**基因漂移风险评估**于一体的综合性科研辅助软件。系统旨在为转基因作物的安全隔离距离设定提供科学依据。

软件主要功能包括：通过串口实时采集风速、风向、温湿度及GPS位置数据；集成百度地图API实现种植区域的可视化框选与管理；利用**高斯烟羽模型（Gaussian Plume Model）**模拟花粉在风场作用下的三维扩散过程；基于花粉竞争模型计算基因漂移概率，并生成包含**安全距离标注**的风险热力图。

## 4. 系统功能详细说明

本软件主要包含四大功能模块，分别对应主界面的四个选项卡。

### 4.1 监测数据模块 (Monitoring Data)
该模块用于实时显示环境传感器的状态。
- **地图定位**：左侧内嵌百度地图，实时显示当前监测设备的GPS位置。
- **仪表盘显示**：右侧通过数字仪表盘实时刷新**温度、湿度、风速、风向**数据。
- **硬件连接管理**：支持选择串口号（COM口）和波特率，提供“连接”与“断开”控制。支持“模拟数据”模式用于无硬件环境下的演示。

### 4.2 实时记录模块 (Real-time Records)
- **数据日志**：以文本列表形式记录每一次采集到的环境数据（包含时间戳）。
- **数据导出**：支持将历史记录一键导出为 CSV 格式文件，便于后续数据分析。

### 4.3 花粉浓度扩散模块 (Pollen Concentration Diffusion)
该模块用于模拟转基因花粉在特定气象条件下的扩散情况。
- **参数配置**：
    - **气象参数**：支持手动输入或从实时监测数据中同步风速、风向、大气稳定度等参数。
    - **源强参数**：设置源强 Q（粒/s）、有效源高 H 等物理参数。
- **区域设置**：
    - **地图交互**：支持在地图上直接框选**转基因种植区（源）**和**非转基因种植区（受体）**。
    - **相对位置控制**：提供精确的区域移动功能，可设置非转基因区相对于源区域的方位（如正东、正南）及**边界距离**（如相距 500米）。
- **模拟计算**：
    - 采用多线程并行计算技术运行高斯烟羽模型。
    - **可视化输出**：在地图底图上叠加花粉浓度等高线图（半透明热力图），直观展示高浓度区域的分布。
    - **图表分析**：右侧展示非转基因区域内的花粉浓度分布曲线。

### 4.4 基因漂移概率模块 (Gene Drift Probability)
该模块基于花粉浓度数据，进一步评估基因漂移风险，是系统的核心评估功能。
- **模型参数**：支持调整冠层拦截系数 ($k_p$)、叶面积指数 ($L$)、沉降速度 ($v_d$) 及花粉竞争参数 ($c_p$)。
- **可视化评估**（包含三部分图表）：
    1.  **全局漂移概率分布图**：
        - 左侧显示大范围的基因漂移概率热力图，叠加真实地图背景。
        - 清晰框出非转基因区域的位置，展示宏观风险分布。
    2.  **局部风险详情图**（非转基因区域）：
        - 聚焦于非转基因种植区域内部。
        - 绘制 **1%** 和 **0.1%** 基因漂移概率的等值轮廓线。
        - **智能标注**：自动计算并标注轮廓线与坐标轴、区域边界的**精确交点距离**（如 "8.9m"），并在交点处绘制指示点，直观反映风险边界。
    3.  **统计与安全距离**：
        - 右侧展示区域内平均漂移概率随距离变化的曲线。
        - **自动计算安全距离**：系统自动分析全域数据，计算出基因漂移概率降至 **0.1%** 以下所需的最小隔离距离，并以醒目的绿色大号字体显示（如 "605 m"）。
- **数据导出**：支持将计算生成的概率矩阵导出为 CSV 文件。

## 5. 软件使用流程

1.  **启动软件**：运行 `main.py` 进入主界面。
2.  **连接设备**：
    - 在顶部选择对应的串口号（如 `COM3`）和波特率（默认 `115200`）。
    - 点击“连接”按钮，确认接收到实时数据。
3.  **设置种植场景**：
    - 切换至“花粉浓度扩散”页。
    - 点击“选择转基因区域”和“选择非转基因区域”，在地图上框选目标地块。
    - 或使用“区域设置”面板，输入精确的经纬度或设置相对距离（例如：设置非转基因区位于转基因区正东方向 200米处）。
4.  **运行扩散模拟**：
    - 确认气象参数无误后，点击“运行模拟”按钮。
    - 等待进度条完成，观察地图上的浓度分布。
5.  **评估漂移风险**：
    - 切换至“基因漂移概率”页。
    - 设置生物学参数（或保持默认）。
    - 点击“生成热力图”。
    - **查看结果**：观察左侧的风险轮廓线标注，以及右侧计算出的**安全距离**数值。
    - 如有需要，点击“输出csv形式的基因漂移概率”保存数据。

## 6. 技术架构与创新点

1.  **多模型耦合**：创新性地将高斯烟羽物理扩散模型与生物竞争模型结合，实现了从“物理扩散”到“生物漂移”的全链条模拟。
2.  **高精度可视化**：利用 Matplotlib 与百度地图的深度融合技术，实现了模拟结果与地理信息的精准叠加。特别是独创的**轮廓线智能求交算法**，能够自动标注风险边界的具体数值，极大方便了科研人员读取数据。
3.  **动态交互设计**：支持基于边界距离的相对位置移动算法，解决了传统基于中心点距离计算不直观的问题，符合农业种植隔离带设置的实际需求。
4.  **多线程并行计算**：核心算法采用多线程与多进程混合架构，确保在处理高分辨率网格模拟时，软件界面依然保持流畅响应。
